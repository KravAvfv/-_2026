# ЛР 1 — Відділення банку: VLAN і маршрутизація між ними (варіант 08)

Шаблону .pkt від викладача немає, тому спершу будуємо його самі за таблицею брифу (крок А), потім виконуємо роботу (кроки Б–Д). Команди копіюйте з файлів у папці `CLI/` і вставляйте у вкладку **CLI** пристрою (Ctrl+V або права кнопка → Paste). Скриншоти — **усе вікно Packet Tracer** з видимою приміткою «Варіант 08, Кравченко» (Spectacle: «Активне вікно», або Meta+Shift+PrintScreen). Зберігайте їх як `Лабораторна робота 1/Скриншоти/1.png … 6.png`.

Порада: Options → Preferences → Font → збільште шрифт CLI до 14–16, а вікно CLI розтягніть — так текст буде читатися у звіті.

## Б. Скриншот 1 — проблема

## В. Питання 1 — VLAN і порти

BR-SW1 → CLI → Enter → вставте `CLI/1_комутатор_VLAN_і_порти.txt`:

```
enable
configure terminal
hostname BR08-SW1
no ip domain-lookup
banner motd #BANK N | VARIANT 08#
vlan 93
 name KASA
vlan 115
 name MANAGERS
vlan 19
 name ABS
vlan 126
 name ATM_POS
vlan 224
 name IOT
vlan 76
 name GUEST
vlan 904
 name PARKING
 exit
interface range fastEthernet 0/1 - 2
 switchport mode access
 switchport access vlan 93
 exit
interface fastEthernet 0/3
 switchport mode access
 switchport access vlan 115
 exit
interface fastEthernet 0/4
 switchport mode access
 switchport access vlan 19
 exit
interface range fastEthernet 0/5 - 6
 switchport mode access
 switchport access vlan 126
 exit
interface range fastEthernet 0/7 - 8
 switchport mode access
 switchport access vlan 224
 exit
interface range fastEthernet 0/9 - 10
 switchport mode access
 switchport access vlan 76
 exit
end
show vlan brief
```

Останньою виконується `show vlan brief` → **скриншот 2** (KASA Fa0/1-2 … GUEST Fa0/9-10; у default — Fa0/11–24 і Gig0/2; PARKING 904 порожній).

## Г. Питання 2 — магістраль, підінтерфейси, адреси

1. На BR08-SW1 вставте `CLI/2_комутатор_магістраль.txt`:

```
configure terminal
interface gigabitEthernet 0/1
 switchport mode trunk
 switchport trunk native vlan 904
 switchport trunk allowed vlan 93,115,19,126
 end
copy running-config startup-config

show interfaces trunk
```

   Після `show interfaces trunk` → **скриншот 3** (Gig0/1 on 802.1q, native 904, allowed 19,93,115,126).

2. BR-R1 → CLI → на питання «initial configuration dialog» відповідайте `no` → вставте `CLI/3_маршрутизатор.txt`:

```
enable
configure terminal
hostname BR08-R1
no ip domain-lookup
banner motd #BANK N | VARIANT 08#
interface gigabitEthernet 0/0
 no shutdown
 exit
interface gigabitEthernet 0/0.93
 description KASA
 encapsulation dot1Q 93
 ip address 10.206.93.1 255.255.255.0
 exit
interface gigabitEthernet 0/0.115
 description MANAGERS
 encapsulation dot1Q 115
 ip address 10.206.115.1 255.255.255.0
 exit
interface gigabitEthernet 0/0.19
 description ABS
 encapsulation dot1Q 19
 ip address 10.206.19.1 255.255.255.0
 exit
interface gigabitEthernet 0/0.126
 description ATM_POS
 encapsulation dot1Q 126
 ip address 10.206.126.1 255.255.255.0
 exit
end
copy running-config startup-config

show ip interface brief
show ip route
```

   Повідомлення CDP про невідповідність native VLAN (якщо з'являться) ігноруйте — так задумано.
3. На всіх 10 ПК поставте адреси з колонок «Адреса за карткою» і «Шлюз» (Desktop → IP Configuration → Static). Швидше: Command Prompt → `ipconfig <адреса> 255.255.255.0 <шлюз>`, наприклад `ipconfig 10.206.93.11 255.255.255.0 10.206.93.1`.
4. Розтягніть вікно CLI BR08-R1 так, щоб було видно результат `show ip interface brief` і `show ip route` (чотири рядки C) → **скриншот 4**.

## Д. Питання 3 — Simulation Mode

1. Праворуч унизу перемкніться на **Simulation**. Edit Filters → Show All/None → залиште лише **ICMP** і **ARP**.
2. Інструмент **Add Simple PDU** (конвертик): клік по джерелу, клік по призначенню; далі **Capture / Forward**, поки пакет не дійде або не зникне. Перед кожною перевіркою — **Reset Simulation**.
3. Перевірки: 1) ABS-1 → Mgr-1 (так); 2) Kasa-1 → ATM-1 (так); 3) Guest-1 → Mgr-1 (ні); 4) Sensor-1 → Kasa-1 (ні); 5) Sensor-1 → Cam-1 (так).
4. **Скриншот 5** — перевірка 1: у Event List клікніть кольоровий квадратик події на ділянці BR08-SW1 → BR08-R1, відкриється PDU Information; у вкладці Outbound PDU Details видно **802.1Q, TCI / VLAN: 19** (або 115 на зворотній ділянці). На скриншоті мають бути Event List, вікно PDU і примітка.
5. **Скриншот 6** — перевірка 3: проганяйте Capture / Forward, доки ARP-запит від Guest-1 не дійде до Guest-2 і там не зникне (Guest-2 його відкидає), а ICMP-конвертик стоїть на Guest-1. Видно місце, де пакет зник, і Event List.
6. Якщо будь-яка перевірка дала не той результат, що в дужках — напишіть мені, я виправлю таблицю.
7. File → Save (Ctrl+S). Файл .pkt знадобиться на захисті.
