## Б. Скриншот 1 — проблема

Intruder → Command Prompt → `ping 192.168.1.11` (проходить). Потім BR-SW1 → CLI → Enter → `enable` → `show mac-address-table` (є рядок з MAC Intruder на Fa0/22). Розставте вікна так, щоб було видно обидва → **скриншот 1**.

## В. Питання 1 — вільні порти в карантин

Вставте `CLI/1_вільні_порти_карантин.txt`:

```
enable
configure terminal
hostname BR08-SW1
no ip domain-lookup
banner motd #BANK N | VARIANT 08#
vlan 523
 name QUARANTINE
 exit
interface range fastEthernet 0/6 - 7
 description FREE-SERVER
 switchport mode access
 switchport access vlan 523
 shutdown
 exit
interface range fastEthernet 0/8 - 21
 description FREE-OTHER
 switchport mode access
 switchport access vlan 523
 shutdown
 exit
interface range fastEthernet 0/22 - 24
 description FREE-HALL
 switchport mode access
 switchport access vlan 523
 shutdown
 exit
end
show interfaces status
copy running-config startup-config
```

Результат `show interfaces status` (Fa0/6–24 disabled, VLAN 523) → **скриншот 2**. Пінг з Intruder тепер не проходить.

## Г. Питання 2 — Port Security

1. На **Kasa-2, Kasa-3, ABS-1, SRV-1**: Command Prompt → `ipconfig /all` → рядок Physical Address (вигляд `0001.4A2B.3C4D`). Надішліть мені ці чотири адреси (або запишіть у `Лабораторна робота 2/Скриншоти/macs.txt` рядками `Kasa-2 0001.4A2B.3C4D`) — я перегенерую файл команд з ними. Або просто замініть `<MAC …>` у файлі перед вставкою.
2. Вставте `CLI/2_port_security.txt`:

```
configure terminal
interface fastEthernet 0/1
 description KASA-1
 switchport mode access
 switchport port-security
 switchport port-security maximum 1
 switchport port-security mac-address sticky
 switchport port-security violation shutdown
 exit
interface fastEthernet 0/2
 description KASA-HUB
 switchport mode access
 switchport port-security
 switchport port-security maximum 2
 switchport port-security mac-address <MAC Kasa-2>
 switchport port-security mac-address <MAC Kasa-3>
 switchport port-security violation shutdown
 exit
interface fastEthernet 0/3
 description MGR-1
 switchport mode access
 switchport port-security
 switchport port-security maximum 1
 switchport port-security mac-address sticky
 switchport port-security violation restrict
 exit
interface fastEthernet 0/4
 description ABS-1
 switchport mode access
 switchport port-security
 switchport port-security maximum 1
 switchport port-security mac-address <MAC ABS-1>
 switchport port-security violation protect
 exit
interface fastEthernet 0/5
 description SRV-1
 switchport mode access
 switchport port-security
 switchport port-security maximum 1
 switchport port-security mac-address <MAC SRV-1>
 switchport port-security violation protect
 exit
end
```

3. Щоб sticky-порти вивчили адреси: з Kasa-1 `ping 192.168.1.14` (Mgr-1) і з Mgr-1 `ping 192.168.1.11`; також ABS-1 → `ping 192.168.1.16`.
4. Вставте `CLI/3_перевірка_port_security.txt`. Вивід `show port-security` (CurrentAddr: Fa0/2 = 2) → **скриншот 3**; вивід `show port-security address` (SecureSticky і SecureConfigured) → **скриншот 4**.

## Д. Питання 3 — Intruder на робочих портах

Перед кожною перевіркою: Intruder → IP 192.168.1.99 / 255.255.255.0 (вже стоїть). Після кожної — `show port-security interface fastEthernet 0/<порт>` і `show interfaces status`.

1. **Перевірка 1:** Kasa-1 → `ping 192.168.1.14` (проходить).
2. **Перевірка 2:** Intruder у Fa0/22 → `ping 192.168.1.11` (не проходить, порт вимкнений).
3. **Перевірка 3 (shutdown):** видаліть кабель Kasa-1 ↔ Fa0/1, підключіть Intruder до Fa0/1, з Intruder `ping 192.168.1.14`. Порт стає err-disabled. На комутаторі: `show port-security interface fastEthernet 0/1` і `show interfaces status` → **скриншот 5**.
4. **Відновлення (одразу після перевірки 3):** видаліть кабель Intruder, поверніть Kasa-1 на Fa0/1, вставте `CLI/4_відновлення_Fa0_1.txt`, потім з Kasa-1 `ping 192.168.1.14` (проходить) → **скриншот 6** (видно connected і успішний пінг). Intruder поверніть на Fa0/22.
5. **Перевірка 4 (restrict):** Mgr-1 від Fa0/3 відключіть, Intruder → Fa0/3, `ping 192.168.1.11`; `show port-security interface fastEthernet 0/3` — порт Secure-up, Security Violation Count > 0. Зробіть додатковий знімок `Скриншоти/д4.png` (лише для звірки чисел). Поверніть Mgr-1.
6. **Перевірка 5 (protect):** SRV-1 від Fa0/5 відключіть, Intruder → Fa0/5, `ping 192.168.1.11`; `show port-security interface fastEthernet 0/5` — Secure-up, лічильник 0. Знімок `Скриншоти/д5.png`. Поверніть SRV-1, Intruder — на Fa0/22.
7. `copy running-config startup-config`, File → Save. Файл .pkt здається разом зі звітом.
