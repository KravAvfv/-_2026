# Прототип АРМ «Щит-Лінк» — курсова робота з ПІС

Кравченко П., гр. ІР-31. Веб-застосунок (Python 3, Flask) поверх бази даних PostgreSQL 18: схема `db/schema.sql`,
функції, тригери, представлення, ролі й журнал аудиту з геш-ланцюгом `db/impl.sql`, тестові дані `db/seed.py`.
Організація РЦПДО «Щит-Північ» і всі дані вигадані.

## Запуск

Потрібні Python 3.11+ і PostgreSQL 18 (сервер, утиліти `initdb` і `pg_ctl` мають бути в `PATH`).
Перевірено на Linux.

```sh
git clone https://github.com/KravAvfv/-_2026.git shchit && cd shchit
python3 -m venv .venv
.venv/bin/pip install -r coursework_final/app/requirements.txt
.venv/bin/python coursework_final/app/serve.py
```

Відкрийте http://127.0.0.1:5080. Скрипт сам створює тимчасову базу даних, заповнює її тестовими даними й запускає
застосунок; Ctrl+C зупиняє його і видаляє базу. Інший порт: `PORT=5090 .venv/bin/python coursework_final/app/serve.py`.

Пароль усіх облікових записів — `shchit-demo`.

| Логін | Роль |
|---|---|
| `och1` | оперативний черговий |
| `obu1` | офіцер бойового управління |
| `an1` | аналітик |
| `cmd01`, `cmd02`, … | командири розрахунків |
| `pilot01`, … | оператори |
| `r06_1` | пост спостереження |
| `r07_1` | технік |
| `r08_1` | логіст |
| `r09_1` | аналітик ефективності |
| `r10_1` | адміністратор |
| `r11_1` | офіцер кібербезпеки |
| `r12_1` | начальник центру |
| `r13_1` | інструктор |
