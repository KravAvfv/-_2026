# Навчальні роботи 2026 — Кравченко П., гр. ІР-31

КНУ імені Тараса Шевченка, ФІТ. Репозиторій містить матеріали дисциплін, готові звіти (`.docx`) та скрипти,
якими ці звіти згенеровано. Наскрізна предметна область ПІС і ТСПП — умовний РЦПДО «Щит-Північ» та
IoT-платформа «Щит-Лінк» (див. [`DOMAIN_KNOWLEDGE_BASE.md`](DOMAIN_KNOWLEDGE_BASE.md)).

## Структура

| Шлях | Вміст |
|---|---|
| корінь (`ПІС_*.pdf`, `лб*.docx`, `Корисна інфа *.pdf`) | матеріали ПІС: лекції, завдання лабораторних, література, титульна сторінка |
| `lab1/` … `lab7/` | лабораторні роботи ПІС |
| [`coursework_final/`](coursework_final/) | курсова робота з ПІС: записка та прототип АРМ «Щит-Лінк» ([запуск](coursework_final/app/README.md)) |
| [`Технології створення програмних продуктів/`](<Технології створення програмних продуктів/>) | матеріали ТСПП: лекції Л1–Л8, завдання ПР1–ПР4, література викладача, титульні сторінки |
| `tspp_work/` | практичні (`pract1`–`pract4`) та лабораторні (`lab1`–`lab2`) роботи ТСПП |
| [`Кібернетична безпека підприємств/`](<Кібернетична безпека підприємств/>) | матеріали дисципліни: лекції, методичка, титульна сторінка |
| `cybersec_work/` | лабораторні роботи з кібербезпеки |
| [`ТАУ/`](ТАУ/) | матеріали ТАУ та готові ПЗ (варіант 8) |
| `tau_work/` | генератори звітів ТАУ |
| [`Системи банкової безпеки/`](<Системи банкової безпеки/>) | матеріали дисципліни (картки, шаблони, бланки) і готові роботи в `Практична N/Готово/` (варіант 08) |
| `bank_work/` | генератори практичних робіт із систем банкової безпеки (заповнення шаблонів Excel, схеми PowerPoint, перевірка формул) |
| [`Суфлери/`](Суфлери/) | тексти до захисту кожної роботи: `00_Сценарій_демонстрації.docx` (покроковий сценарій показу всієї роботи) і суфлери до окремих тем ([покажчик](Суфлери/README.md)) |
| `tools/` | спільний інструментарій: рендеринг діаграм, збирання й перевірка звітів, експорт у draw.io |
| `CLAUDE.md`, `.claude/skills/` | інструкції та процедури, за якими виконувались роботи |

У кожній робочій папці: `model*.py` — дані моделі, `make_*.py` — генерація діаграм і `report.yaml`,
`diagrams/` — джерела діаграм, `drawio/` — діаграми у форматі draw.io, `*_Кравченко_ІР-31.docx` — готовий звіт.

## Як відтворити звіт

Потрібно: Python 3 з `.venv` (python-docx, lxml, Pillow, PyYAML, pypdf), Mermaid CLI `mmdc`,
`npm install` у `tools/bpmn/`, `plantuml.jar` (див. [`tools/plantuml/README.md`](tools/plantuml/README.md)),
OnlyOffice x2t для PDF. Приклад:

```sh
.venv/bin/python tspp_work/pract4/make_pract4.py
.venv/bin/python tools/build_report.py tspp_work/pract4/report.yaml --pdf
.venv/bin/python tools/check_report.py tspp_work/pract4/ПР4_Кравченко_ІР-31.docx --spec tspp_work/pract4/report.yaml
```

Банківська безпека: `cd bank_work && ../.venv/bin/python make_prN.py` (потрібні `openpyxl`, `python-pptx`,
`formulas` — останній перераховує формули шаблону й перевіряє, що всі «Перевірки» = «ОК»). ТАУ:
`.venv/bin/python tau_work/make_tau.py 4 5 6 && .venv/bin/python tau_work/make_reports.py 4 5 6`.
Суфлери й сценарії демонстрації: `.venv/bin/python tools/make_speeches.py`.

Попередні перегляди, PDF і `.svg` не зберігаються в репозиторії — вони відтворюються цими командами.
